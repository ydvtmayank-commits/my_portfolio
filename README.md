## ✏️ How to Customize Your Information

All details are cleanly organized and easily editable:

### 1. Contact Information & Email
Open `index.html` in any code editor (or Notepad / VS Code):
- Search for `mayank.mech.engg@example.com` and replace it with your actual email address.
- In the `<div class="social-links">` section, update the `href="#"` links with your actual LinkedIn profile, GitHub, or Instagram profile link.

### 2. University / College Name
In the `#education` section of `index.html`:
- Find `<p class="institution">... Engineering University Program</p>` and add the exact name of your current engineering university or college.

### 3. Adding Your Own Project Photos
- Create an `images/` folder inside this directory.
- Add pictures of cars you've worked on, engine parts, CAD screenshots, or workshop sessions.
- In `index.html`, you can easily add `<img>` tags inside the project cards or modal.

## 🌐 How to Host It Online for Free (Shareable Link)

### Option A: GitHub Pages (Recommended for Engineers)
1. Create a free account on [GitHub.com](https://github.com).
2. Create a new repository named `mayank-portfolio` (or `mayank-yadav.github.io`).
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
4. Go to **Settings** -> **Pages** -> under Branch, select `main` -> click **Save**.
5. Your portfolio will be live in 1 minute at `https://<your-username>.github.io/mayank-portfolio/`!

### Option B: Netlify Drop (Takes 30 seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this whole `mayank portfolio` folder into the browser window.
3. You will immediately get a live shareable URL!
